# 전기기사 필기 CBT

전기기사 학습용 React + TypeScript + Vite 정적 앱. 로그인·서버·유료 API 없이 브라우저에 기록을 저장합니다.

**구현·로컬 검증과 GitHub 반영을 준비했으며 GitHub Pages는 활성화·배포하지 않았습니다.** 기본 문제은행은 자체 제작 내부 검수 200문항으로 **목표 1,000문항에 800문항 부족**합니다. 공식 규칙 원문 대조와 최신 KEC 검증은 접근 제한으로 미완료입니다.

## 기능

- 대시보드, 실전 모의시험, 과목별 랜덤 학습, 결과·상세 해설, 오답 복습, 북마크, 과목 통계·최근 시험.
- 5과목에서 20개씩 100문항, 150분의 학습용 시험. 평균 60점 이상 + 모든 과목 40점 이상 판정. 미응답은 오답이며 결과에 별도 집계합니다.
- 절대 종료 시각에 따른 타이머·만료 자동 제출, 답안 수정·즉시 저장·새로고침 복원, 중복 제출 및 만료 후 답안 수정 차단.
- 실전은 답안 선택 후, 랜덤은 채점 후 Space로 다음 문제. 마지막 실전 문제에서는 자동 제출하지 않습니다. 입력·IME·수정키·길게 누르기·메뉴·대화상자·네이티브 버튼 동작을 보호합니다.
- JSON/CSV 양식과 로컬 가져오기, 원자적 형식 검사, ID/정규화 본문·보기 중복 제거, 검증 대기, 근거 기록 후 로컬 승인, 검색·상태 필터·페이지 목록·내보내기.
- 브라우저별 학습 기록 백업과 확인 후 초기화. 손상된 저장 원본을 자동 덮어쓰지 않으며 저장 실패를 표시합니다.
- PC/모바일 반응형, 작은 높이의 독립 스크롤 메뉴. 학습 기준·연도 버전 선택 메뉴 및 상단 상시 면책 배너는 없습니다. 비공식 표시와 검수 한계는 푸터·문제은행·문서에 둡니다.

## 로컬 실행과 검증

Node.js **24.19.0** (`.node-version`, package 요구 ≥22.12.0), npm 및 Python 3(문항 재생성 시)를 사용합니다. 기존 체크아웃에서 작업하며 별도 worktree는 필요 없습니다.

```sh
npm ci
npm run dev
npm test
npm run build
# 최초 브라우저 설치가 필요할 때만:
npx playwright install --with-deps chromium
npm run test:e2e
```

`npm run dev`는 개발 서버, `npm run preview -- --port 4173`은 빌드 산출물의 로컬 확인용입니다. Vite base는 `/Engineer-Electricity-CBT/`입니다. 테스트는 데스크톱 Chromium과 Pixel 7 에뮬레이션에서 실행합니다. 설치된 `/usr/bin/chromium`을 자동 사용하며 다른 실행 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정할 수 있습니다. CI에서는 Playwright의 Chromium을 설치합니다. **실물 PC·모바일/다른 브라우저를 검증했다고 주장하지 않습니다.**

문항 재생성과 검사는 다음과 같습니다. 생성기는 기존 기본 JSON/양식을 갱신하므로 변경 후 diff를 검토하세요.

```sh
python3 scripts/generate_bank.py
npm test
```

실제 검사 수와 범위는 [검증 기록](docs/verification.md), 화면은 [스크린샷 폴더](docs/screenshots/)에 있습니다.

## 시험 규칙과 문제 수

설정은 [`src/qualification.json`](src/qualification.json)에 분리했습니다. 현재 값은 전기기사에 대해 일반적으로 알려진 규칙을 적용한 **학습용 잠정 설정**이며, Q-Net/국가법령정보센터 연결이 CONNECT 403으로 거부되어 공식 원문을 읽지 못했습니다. [공식 대조 기록](docs/qualification-verification.md)에 시도한 URL·설정·확인 상태와 후속 절차를 기록했습니다. 읽지 않은 공식 자료를 정답 근거로 표시하지 않습니다.

| 과목 | 내부 검수 문항 | 계산형 | 개념형 |
| --- | ---: | ---: | ---: |
| 전기자기학 | 40 | 40 | 0 |
| 전력공학 | 40 | 40 | 0 |
| 전기기기 | 40 | 40 | 0 |
| 회로이론 및 제어공학 | 40 | 40 | 0 |
| 전기설비기술기준 | 40 | 0 | 40 |
| 합계 | **200** | **160** | **40** |

원문 기출 **0**, 복원 **0**, 자체 제작 **200**, 검증 대기 **0**, 외부 전문가 검수 **0**입니다. 목표 대비 부족 수는 **800**입니다. 계산형은 **16유형 × 10조건**으로, 추가 숫자 변형 144개를 포함합니다. 200개의 독립 개념·기출이 아닙니다. 모의시험은 유형 우선 추출 후 고유 ID로 보충하므로 같은 family의 숫자 변형이 함께 나옵니다.

AI 일반 지식으로 새로 작성한 원고이며 공식 시험 범위·난이도·배분을 재현했다는 의미가 아닙니다. 설비 과목은 법정 수치를 제외한 원리 문제로 최신 KEC 법규 학습을 대체하지 않습니다. 연도·회차는 모두 null입니다. `reviewed`는 내부 문장·정답 검토와 자동 계산·중복 검사를 뜻하며 공식 대조나 외부 전문가 검수를 뜻하지 않습니다. [작성·검수 기록](docs/question-review.md)과 [문항 감사 데이터](docs/bank-audit.json)를 확인하세요.

## 저장과 자료 이용

저장 키는 `engineer-electricity-cbt:v1`로 전기기능사와 분리했습니다. 최근 응답 5,000개·시험 30회를 보관합니다. 진행 중 시험·연습·오답·북마크·로컬 등록 문항을 보존하며 JSON 백업을 내보냅니다. **학습 기록 백업을 UI로 복원하는 기능은 없습니다.** 초기화는 확인 후 사용자 기록과 로컬 문항만 지우고 기본 문항을 유지합니다.

다른 origin·브라우저의 기록은 공유되지 않습니다. 같은 origin의 프로젝트도 각자 namespace를 사용합니다. iframe·시크릿 모드·저장 차단 환경에서는 저장이 제한될 수 있습니다. 다른 origin iframe 및 실기기의 개인정보 보호 설정 검증은 미실행입니다. 로컬 시계를 바꾸면 정적 앱 타이머 계산에 영향을 줄 수 있습니다.

코드는 MIT, 새 자체 제작 데이터·양식은 CC BY 4.0입니다. 문항의 저장소 링크는 작성 기록이지 외부 정답 증명이 아닙니다. 로컬로 가져온 타인 자료의 이용 권한은 사용자가 따로 확인해야 하며 공용 GitHub 문제은행에 자동 게시되지 않습니다.

## 사용자가 직접 GitHub Pages에 배포하는 방법

에이전트는 **Pages 활성화, Pages 설정 변경, 배포 workflow 실행·재실행, 배포 API 호출을 하지 않았습니다.**

기존 체크아웃과 원격 main에는 README만 있고 workflow가 없었습니다. GitHub API에서 기존 Pages Source를 읽는 요청도 Forbidden으로 거부되어, main의 기존 브랜치 게시 설정을 추정하지 않고 **새 브랜치 `feat/engineer-cbt-20261021`에 반영**합니다. main에는 자동 병합하지 않습니다. 이 새 브랜치는 사전에 존재하지 않았으므로 기존 Pages 게시 대상으로 지정돼 있지 않았습니다.

1. GitHub에서 새 작업 브랜치를 검토합니다. 공식 규칙 대조·문항 보완이 남은 학습용 버전임을 확인하세요.
2. **main으로 병합하기 전**, 저장소 Settings → Pages에서 Source를 확인하고 **GitHub Actions**로 직접 설정합니다. `Deploy from a branch`가 main을 감시하도록 남아 있다면 먼저 변경하여 병합 푸시가 바로 게시되는 상황을 막으세요. Pages 기능을 활성화할지 여부도 사용자가 결정합니다.
3. 검토한 작업을 main에 병합합니다. `.github/workflows/ci.yml`은 push/PR에서 검증만 하며 배포 권한·배포 단계가 없습니다. 원격 CI 성공을 확인하세요.
4. GitHub Actions → **Manual GitHub Pages deployment** → **Run workflow**에서 **main**을 골라 사용자가 직접 실행합니다. `.github/workflows/pages.yml`은 `workflow_dispatch`만 수신하며 validate/deploy 모두 `main` + 수동 이벤트 조건을 검사합니다. 테스트·빌드·브라우저 검증에 성공해야 deploy로 넘어갑니다.
5. 조직·저장소 정책에 따라 Pages 사용 및 `github-pages` 환경 승인이 필요할 수 있습니다. 배포 job만 `pages: write`, `id-token: write`를 받습니다. 에이전트에게 별도 토큰을 제공할 필요는 없습니다.
6. 사용자 배포 후 예상 기본 주소는 **https://YunSangYeong.github.io/Engineer-Electricity-CBT/** 입니다. 현재 게시/접속 성공을 확인한 주소가 아닙니다. 대시보드·두 모드·저장·Space·모바일 메뉴·직접 경로 새로고침과 실제 사용하는 iframe을 확인하세요.

배포 이력과 공개 사이트 동작은 사용자 배포 후 확인 대상입니다. 이 작업에서 로컬 검증, Git 원격 반영, 원격 CI, 공개 배포는 각각 구분하여 보고합니다.
