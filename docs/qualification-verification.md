# 전기기사 시험 규칙 대조 기록

확인 시도일: 2026-10-21. 대상은 **전기기사 필기**이며 전기기능사나 전기산업기사, 실기가 아니다.

| 설정 | 현재 학습용 적용값 | 공식 원문 대조 |
| --- | --- | --- |
| 과목 | 전기자기학 / 전력공학 / 전기기기 / 회로이론 및 제어공학 / 전기설비기술기준 | 미완료 |
| 출제 | 과목별 20개, 합계 100개, 객관식 4지선다 | 미완료 |
| 시간 | 과목별 30분을 합한 150분 | 미완료 |
| 배점 | 과목별 100점(문항당 5점), 전체 평균 100점 만점 | 미완료 |
| 합격 | 전체 평균 60점 이상이면서 각 과목 40점 이상 | 미완료 |
| 미응답 | 내부 모의시험에서 오답으로 계산 | 앱 정책 |
| KEC 및 출제기준 적용판 | 미확인, 법정 수치·조항 문제 미수록 | 미완료 |

이는 일반적으로 알려진 규칙을 AI의 일반 지식으로 적용한 **잠정 학습 설정**이다. 전기기능사의 60문항·60분·과락 없음 규칙을 복사하지 않았다. 공식 문서를 읽어 검증했다고 주장하지 않는다. 설정은 `src/qualification.json`에 모았다. 채점은 반올림한 표시 점수가 아닌 정답 수 비율로 평균과 과락을 모두 검사한다. 20문항 중 8개 정답은 40점, 7개는 35점이다. 전체 60개 정답이어도 어느 한 과목이 7개 이하이면 불합격이다.

## 직접 시도한 공식 자료

- Q-Net 종목별 상세정보(전기기사 종목 코드 1150): https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1150
- 같은 경로의 호스트 변형 `q-net.or.kr`도 시도했다.
- 국가법령정보센터 국가기술자격법 시행규칙: https://www.law.go.kr/법령/국가기술자격법시행규칙

HTTPS 요청은 프록시의 **CONNECT tunnel failed, HTTP 403**으로 거부되었다. 원격 공식 서버 본문의 403이라고 단정하지 않으며, 콘텐츠·첨부 출제기준·기출 원문·정답표·이용 조건을 읽지 못했다. 공식 자료에 문제가 없거나 자료가 없다는 증거도 아니다.

환경의 기존 제한 네트워크에 필요한 `www.q-net.or.kr`, `q-net.or.kr`, `www.law.go.kr` 도메인을 설정 **초안**에 추가했다. 저장은 확인되었지만 현재 런타임의 연결 성공이나 게시를 의미하지 않는다. 환경 설정에서 변경을 검토·저장하고 필요 시 환경을 게시한 뒤 해당 요청을 재시도해야 한다. 추가 인증정보는 요청하거나 생성하지 않았다.

## 후속 대조

공식 Q-Net 상세정보와 실제 적용 출제기준 원문을 확보하면 과목 이름·분포·시간·4지선다·배점·평균·과락을 확인하고 URL/문서명/적용기간/확인일을 기록한다. KEC 조항·수치는 적용판과 시점을 확인한 뒤 작성하고 별도 검수한다. 미대조 상태에서 공식 시험 범위·출제 비율·난이도를 재현한다고 표기하지 않는다.
