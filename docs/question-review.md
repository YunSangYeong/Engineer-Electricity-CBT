# 문제은행 작성 및 내부 검수 기록

## 실제 수량과 범위

`src/data/questions-main.json`의 등록 수는 **200**이다. 모두 자체 제작이며 원문 기출 **0**, 복원 **0**, 내부 검수 완료 **200**, 검증 대기 **0**, 제외·중복 등록 **0**, **목표 1,000에 800 부족**이다. 로컬에서 사용자가 가져온 문항은 이 집계에 포함하지 않는다. 1,000문항 인수 기준을 충족했다고 처리하지 않는다.

| 과목 | 내부 검수 완료 | 계산형 | 개념형 |
| --- | ---: | ---: | ---: |
| 전기자기학 | 40 | 40 | 0 |
| 전력공학 | 40 | 40 | 0 |
| 전기기기 | 40 | 40 | 0 |
| 회로이론 및 제어공학 | 40 | 40 | 0 |
| 전기설비기술기준 | 40 | 0 | 40 |
| 합계 | 200 | 160 | 40 |

계산형은 **16유형 × 10조건 = 160문항**이다. 개념형은 40개의 질문이다. 따라서 200개의 독립 출제 유형이 아니다. 계산형의 최초 조건 16개 외에 추가 숫자 변형 144개가 포함된다. 작성 유형 기준은 계산 16 + 개념 질문 40이며 개념들 간 연관성은 있다.

각 계산 과목에 family가 4개뿐이므로 20문항 시험을 구성할 때 유형별 최초 1개를 먼저 선택하고, 나머지 16개는 아직 뽑지 않은 ID 중에서 보충한다. 한 시험 내 ID는 고유하지만 같은 계산 유형의 숫자 변형은 함께 나온다. 과목당 40개 중 20개를 추출한다. 이를 공식 시험의 다양성·난이도·출제 분포 재현으로 해석하면 안 된다.

## 출처·권리·검수의 의미

- 문제와 해설은 **Codex(AI)가 일반 전기공학 지식으로 새로 작성**했다. 읽지 않은 교재, 공식 기출, 출제 연도·회차를 만들지 않았다. 연도와 회차는 모두 null이다.
- 기준 앱의 900문항은 복사하지 않았다. 민간 CBT 사이트의 원문도 복제하지 않았다. 새 자체 제작 데이터와 양식은 CC BY 4.0으로 제공하며 타인 반입 자료의 권리는 별도다.
- 각 문항의 `sourceUrl`은 이 작성·검수 기록을 가리킨다. **외부 정답 근거나 공식 출처가 아니다.** 실제 확인한 외부 문헌을 가장하지 않는다.
- `verificationStatus: reviewed`는 아래 범위의 **AI 내부 검토와 자동 검사**를 뜻한다. 외부 전문가 검수 0건, 공식 출제기준 대조 미완료, 실전 난이도 평가 미실시이다.
- 기출·복원은 이용 가능한 원문과 정답·연도·회차·권리가 검증되지 않아 0개다. 확인되지 않은 자료를 수량 채우기에 사용하지 않았다. 200개는 공식 범위가 대조되지 않은 제한된 연습 자료이며, 전 범위를 충분히 다룬 문제은행이 아니다.

## 실제 검토 절차

1. `scripts/generate_bank.py`에 새 원고와 입력값을 고정하고 Python으로 생성한다. 난수를 쓰지 않으며 ID와 순서는 결정적이다. 다른 자료 파일을 지우지 않는다.
2. 계산형 16개 템플릿의 가정·물리량·공식·SI 변환·대입·해설 문장을 내부 검토했다. 3상 선간/상 전압, 최대 자속/실효 기전력, 슬립 백분율, 출력/입력과 손실, Hz/rad/s, 음의 피드백 부호와 안정성 등을 구분했다.
3. 생성기와 분리한 TypeScript 수식으로 160문항을 재계산한다. 정답 번호·단위·보기 동치·소수 둘째 자리 반올림을 검사한다. Python Decimal half-up과 JS Math.round의 경계 0.875→0.88도 확인한다. 이는 별도 계산 경로지만 외부 검수자의 검토는 아니다.
4. 설비 개념 40개의 본문·정답·오답·해설을 읽고 단일 정답성과 절대적 표현을 검토했다. 법정 수치·조항은 넣지 않았다. 단순 정지와 비상정지 비교의 의미상 겹침은 비상 전원 점검 문제로 교체했다. 보호도체와 본딩, 검전과 재투입 방지, CT 개방과 VT 단락은 서로 다른 학습 질문으로 유지했다.
5. ID 및 NFKC/공백 정규화 본문·정렬 보기로 중복 검사한다. 보기 순서가 달라도 중복으로 처리한다. 의미상 숫자 변형은 family로 명시하여 독립 개념 수에 포함하지 않는다. 모든 문항의 의미상 독립성에 대한 외부 판정은 받지 않았다.
6. 재생성 전후 JSON과 CSV/JSON 양식의 해시가 같음을 확인한다. 실제 결과와 파일 해시는 `docs/bank-audit.json`, 기능 검사 기록은 `docs/verification.md`에 둔다.

공식 출제기준·최신 KEC의 검증이 막혀 있고 현재 작성 유형이 제한되어 있다. 더 많은 단원과 독립 유형을 확보·검수하여 800개를 보완해야 한다. 숫자 조건을 더 늘리는 것만으로 범위 검증이나 검수의 질이 개선되었다고 주장하지 않는다.
