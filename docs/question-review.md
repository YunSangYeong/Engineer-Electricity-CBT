# 문제은행 작성 및 내부 검수 기록

## 실제 수량과 범위

`src/data/questions-main.json`의 등록 수는 **1,000**이다. 모두 자체 제작이며 원문 기출 **0**, 복원 **0**, 내부 검수 완료 **1,000**, 검증 대기 **0**, 제외·중복 등록 **0**, **목표 1,000에 부족 0**이다. 로컬에서 사용자가 가져온 문항은 이 집계에 포함하지 않는다. 등록 수량 기준은 충족했으나 공식 대조·외부 전문가 검수까지 완료한 것으로 해석하지 않는다.

| 과목 | 내부 검수 완료 | 계산형 | 개념형 |
| --- | ---: | ---: | ---: |
| 전기자기학 | 200 | 200 | 0 |
| 전력공학 | 200 | 200 | 0 |
| 전기기기 | 200 | 200 | 0 |
| 회로이론 및 제어공학 | 200 | 200 | 0 |
| 전기설비기술기준 | 200 | 160 | 40 |
| 합계 | 1,000 | 960 | 40 |

계산형은 **96유형 × 10조건 = 960문항**이다. 개념형은 기존 40개다. 계산형의 최초 조건 96개 외에 숫자 변형 864개가 포함된다. 여기서 유형은 작성 템플릿 기준이며 서로 관련된 개념이 있다. 1,000개의 독립 출제 유형이나 기출 문제를 뜻하지 않는다.

기존 계산 16유형×10조건과 개념 40개를 모두 그대로 두고, 과목별 새 계산 16유형×10조건=160개씩 5과목에 **800개**를 추가했다. 기존 200개 전체 필드의 보존은 고정 ID 목록과 SHA-256 회귀 검사로 확인한다. 원본 기준은 `1eade5a03b8f1d0186d4df4dd98364ca9ec64323`이다.

기본 은행은 첫 4과목 각각 20개 계산 family, 설비 과목은 16개 계산 family와 40개 개념 질문이다. 과목별 20문항을 추출하는 기본 시험은 같은 계산 family를 중복하지 않는다. 한 시험의 ID도 고유하다. 다만 서로 관련된 개념은 있으므로 공식 출제범위·난이도·통계적 독립성을 재현했다고 주장하지 않는다. 사용자가 추가한 은행의 유형이 부족할 때는 고유 ID로 보충한다.

## 출처·권리·검수의 의미

- 문제와 해설은 **Codex(AI)가 일반 전기공학 지식으로 새로 작성**했다. 읽지 않은 교재, 공식 기출, 출제 연도·회차를 만들지 않았다. 연도와 회차는 모두 null이다.
- 기준 앱의 900문항은 복사하지 않았다. 민간 CBT 사이트의 원문도 복제하지 않았다. 새 자체 제작 데이터와 양식은 CC BY 4.0으로 제공하며 타인 반입 자료의 권리는 별도다.
- 각 문항의 `sourceUrl`은 이 작성·검수 기록을 가리킨다. **외부 정답 근거나 공식 출처가 아니다.** 실제 확인한 외부 문헌을 가장하지 않는다.
- `verificationStatus: reviewed`는 아래 범위의 **AI 내부 검토와 자동 검사**를 뜻한다. 외부 전문가 검수 0건, 공식 출제기준 대조 미완료, 실전 난이도 평가 미실시이다.
- 기출·복원은 이용 가능한 원문과 정답·연도·회차·권리가 검증되지 않아 0개다. 확인되지 않은 자료를 수량 채우기에 사용하지 않았다. 1,000개도 공식 범위가 대조되지 않은 연습 자료이며, 전 범위를 충분히 다룬 문제은행이 아니다.

## 실제 검토 절차

1. `scripts/generate_bank.py`와 `scripts/expanded_bank.py`에 원고와 입력값을 고정하고 Python으로 생성한다. 난수를 쓰지 않으며 ID와 순서는 결정적이다. 다른 자료 파일을 지우지 않는다.
2. 계산형 96개 템플릿의 가정·물리량·공식·SI 변환·대입·해설 문장을 내부 검토했다. 3상 선간/상 전압, 최대 자속/실효 기전력, 슬립 백분율, 출력/입력과 손실, Hz/rad/s, 음의 피드백 부호와 안정성 등을 구분했다.
3. 생성기와 분리한 TypeScript 수식으로 960문항을 재계산한다. 정답 번호·단위·보기 동치·소수 둘째 자리 반올림을 검사한다. Python Decimal half-up과 JS Math.round의 경계 0.875→0.88도 확인한다. 이는 별도 계산 경로지만 외부 검수자의 검토는 아니다.
4. 설비 개념 40개의 본문·정답·오답·해설을 읽고 단일 정답성과 절대적 표현을 검토했다. 법정 수치·조항은 넣지 않았다. 단순 정지와 비상정지 비교의 의미상 겹침은 비상 전원 점검 문제로 교체했다. 보호도체와 본딩, 검전과 재투입 방지, CT 개방과 VT 단락은 서로 다른 학습 질문으로 유지했다.
5. ID 및 NFKC/공백 정규화 본문·정렬 보기로 중복 검사한다. 보기 순서가 달라도 중복으로 처리한다. 의미상 숫자 변형은 family로 명시하여 독립 개념 수에 포함하지 않는다. 모든 문항의 의미상 독립성에 대한 외부 판정은 받지 않았다.
6. 재생성 전후 JSON과 CSV/JSON 양식의 해시가 같음을 확인한다. 실제 결과와 파일 해시는 `docs/bank-audit.json`, 기능 검사 기록은 `docs/verification.md`에 둔다.

추가 80개 템플릿의 조건·단위·문장 검토 목록과 첫 조건의 풀이를 [계산 유형 검토 목록](family-review.md)에 기록했다. 단위/기준량, 물리 가정, 근사식의 적용 범위와 설비의 가정값/법정값을 구별했다. 원고 검토 중 분포권의 슬롯 설계 조건과 영상분 페이저 표현을 명확히 했다.

공식 출제기준·최신 KEC의 대조와 외부 전문가 검수는 여전히 미완료이다. 숫자 변형을 포함한 1,000문항 등록은 수량 기준 충족이며, 전 범위 법규 적합성·공식 기출 확보나 외부 전문가 검수 완료를 뜻하지 않는다.
